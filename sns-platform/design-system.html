디자인 시스템

AI가 대량 생성한 템플릿이 아니라, 전문 SaaS 디자이너가 설계한 느낌을 목표로 합니다. 모든 화면은 이 토큰과 컴포넌트를 단일 소스로 사용합니다. Linear의 절제, Metricool의 데이터 밀도, Planable의 콘텐츠 중심, Canva의 대형 썸네일 — 원리만 차용합니다.

설계 원칙

절제가 기본

그라데이션·그림자·배지는 '의미 있을 때만'. 장식이 아니라 정보 위계로 구분합니다.

화면마다 다른 구조

메일함식 2단 레이아웃을 모든 화면에 강요하지 않습니다. 업무 성격에 맞게 설계합니다.

콘텐츠를 크게

이미지·영상이 주인공인 화면은 실제 콘텐츠를 크게 보여줍니다.

단일 소스

색·간격·폰트는 CSS 변수 토큰 한 곳에서. 31곳에 흩어진 인라인 스타일을 수렴합니다.

색상

뉴트럴(slate)이 시스템의 90%. 브랜드 블루는 '강조'에만, 상태색은 '의미'에만 씁니다.

뉴트럴

브랜드 (Primary)

상태 (의미 색)

타이포그래피

Pretendard(한글) + Inter(라틴). 한글 가독성이 전문성의 첫인상입니다.

xs · 400보조 설명 · 메타 정보 (tertiary)

간격 · Radius

4px 기준 간격 스케일, 정돈된 radius(6·8·10·12·16). 기존의 제각각(4·5·9·14·20)을 수렴.

아이콘 — Lucide

이모지(📱🏠💬)를 통일된 라인 아이콘으로 교체합니다. 1.5~2px 선 굵기로 전문적 톤.

버튼

Primary는 화면당 1~2개. 나머지는 Secondary/Ghost로 위계를 둡니다.

입력 폼

배지 · 칩

조용한 톤 기본. 상태색은 성공/경고/위험처럼 '의미'가 있을 때만.
