# ADR-001 — DIVOOST 디자인 시스템 도입

- 상태: 제안됨 (Phase 0 완료, 마스터 승인 대기)
- 날짜: 2026-11-14
- 관련 지시: UI 디자인 고도화 지시 1·4·5·6·7·8·9번

## 배경 (Context)

HubOnTrade SNS(sns-platform)는 28개 HTML 화면(약 11,680줄)으로 구성되며,
**스타일이 31개 페이지의 인라인 `<style>`에 흩어져** 있다. 공통 CSS(`sns.css`)는
238줄에 불과하고, radius 값이 제각각(4·5·6·8·9·10·12·14·16·20px), 그라데이션·상태
배지가 남발되어 "AI가 대량 생성한 템플릿" 인상을 준다.

근본 원인은 **단일 소스(Single Source of Truth)의 부재**다. 특정 화면을 재설계하기
전에, 색·타이포·간격·컴포넌트의 공통 규칙을 한 곳에 정의해야 한다.

## 결정 (Decision)

코드 기반 디자인 시스템(DIVOOST Design System, DDS)을 도입한다.

1. **토큰 단일 소스**: `sns-platform/css/design-system.css`
   - 2계층 토큰: Primitive(원시 색 스케일) → Semantic(역할 기반).
   - 컴포넌트는 Semantic 토큰만 참조 → 다크모드는 Semantic만 교체.
2. **네임스페이스 격리**: 모든 토큰 `--ds-*`, 모든 클래스 `.ds-*`.
   - 기존 `sns.css`(.btn/.card/.sidebar)와 **충돌 없음** → 화면을 하나씩 안전하게
     이관 가능(Strangler Fig, H3). 기존 기능·데이터 무변경.
3. **라이브 스타일 가이드**: `sns-platform/design-system.html`
   - Figma를 "그림 기준"으로만 두고, 실제 배포물의 단일 소스는 코드로 둔다.
   - Figma MCP 연결(마스터 토큰 설정 필요) 완료 시 병행/동기화.
4. **폰트**: Pretendard(한글) 자체 호스팅. 한글 가독성이 전문성의 첫인상.
5. **아이콘**: Lucide(이모지 전면 교체). 자체 호스팅.
6. **자체 호스팅(vendor)**: 외부 CDN(unpkg/jsdelivr) 대신 `sns-platform/vendor/`.
   - 이유: 제3자 호출 0건(프라이버시·보안), CDN 장애 무관, 개발환경 검증 가능.

## 트레이드오프 (E2)

| 항목 | 장점 | 단점 / 위험 |
|---|---|---|
| 코드 기반 토큰 | 즉시 시작, 실제 배포물과 1:1 | Figma 대비 디자이너 협업 도구 약함 |
| `.ds-*` 격리 | 기존 화면 무파손, 점진 이관 | 과도기엔 구/신 CSS 공존(용량 일시 증가) |
| 자체 호스팅 | 외부 의존 0, 보안 우수 | 폰트 woff2 2.0MB + Lucide 308KB 리포 용량 ↑ |
| Lucide 전체 UMD | 간단 | 308KB(미사용 아이콘 포함) → 롤아웃 시 트리셰이킹 검토 |

## 거절된 대안 (E4)

- **Tailwind/Flowbite 전면 도입**: 빌드도구 없는 정적 사이트에 빌드 파이프라인을
  강제 → 지시 8번(기존 구조 우선 유지) 위배. (Flowbite는 필요 컴포넌트만 선택 차용 여지 유지)
- **React+Vite 전면 재작성**: 대규모 재작성은 위험(H6, ×3 예산). 지시 1번(기능·데이터
  유지) 및 점진 개선 원칙과 상충.
- **외부 CDN 의존**: 제3자 호출 발생 + 본 개발환경 프록시 정책에서 차단됨.

## 검증 (Verify, G3 / 지시 9번)

- Playwright로 PC 1280px / 모바일 390px / 다크모드 렌더 확인 — 실패 요청 0건.
- 스타일 가이드 페이지에서 전 컴포넌트 육안 검수 완료.

## 영향 / 다음 단계

- 기존 28개 화면은 **아직 무변경**. Phase 1에서 플래그십 화면부터 DDS로 재설계.
- 미결 사항(마스터 승인 필요):
  1. Figma MCP 연결 방식(코드 우선 / Figma 우선 / 병행)
  2. 첫 재설계 플래그십 화면
  3. vendor 에셋(2.3MB) 리포 커밋 여부
