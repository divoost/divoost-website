# DIVOOST SNS 전체 UI v1 — 사용방법

1. `HubOnTrade_SNS_Full_Interactive_UI.html`을 Chrome 또는 Edge로 엽니다.
2. 첫 화면 **오늘의 마케팅 관제**에서 승인·게시·댓글 항목을 눌러 각 업무 화면으로 이동합니다.
3. 상단 **전체 기능**(모바일 하단 **전체**)에서 모든 21개 화면을 볼 수 있습니다.
4. `＋ 콘텐츠`를 누르고 제목·브랜드·채널·상태를 설정해 저장해 보세요.
5. 콘텐츠 상태를 `검수 대기`로 설정 → **승인함**에서 승인 → **게시·예약**에서 예약을 추가합니다.
6. 콘텐츠 캘린더에서 날짜/월을 바꿔 보고, 숏폼에서는 스토리보드와 QC를 테스트하세요.
7. 댓글·DM 화면에서 문의 선택 → FAQ 답변 초안 → 담당자 변경 → 처리 완료를 테스트하세요.
8. 상단 **관리자/베트남 직원/외부 고객**을 변경해 시연 화면 범위를 비교하세요. 실제 보안 권한을 부여하는 것은 아닙니다.
9. `설정·검수`에서 **데모 초기화**를 누르면 화면 데이터가 원래 상태로 돌아갑니다.

## 이 데모에서 되는 일

- 전 화면 이동·선택·필터·폼 저장·승인/수정 요청·콘텐츠 단계 변경·예약 큐·중복 예약 검사
- 카드형 메인 대시보드, 월간 캘린더, 9:16 숏폼 콘티·품질 확인, KOC/광고/라이브/캠페인 등록
- 키워드 관리, 텍스트 기반 게시 최적화, 문의 답변 템플릿, 광고 CSV 로컬 가져오기, 성과 CSV 내보내기
- 샘플 AI 직원 실행 기록, 긴급 중단 시연, 고객사/브랜드/언어/역할 전환
- 브라우저 자체 메모리에 데모 데이터 유지 (가능한 환경에서는 localStorage 사용)

## 현재는 안 되는 일

**실제 SNS 계정 연결, 게시, 메시지 발송, 실시간 댓글 수집, AI 영상 생성, AI 모델 호출, 유료결제, 실시간 성과 연동, EZworks 서버 작업 생성.** 이 작업은 OAuth·공식 API·서버 작업큐·권한 검증·운영 인증이 있어야 하므로 HTML 안에서는 실행하지 않습니다.

다국어 메뉴는 한국어/영어/베트남어/중국어를 시연하며, 화면 본문 전체 번역은 상용 구현 시 진행할 범위입니다.

## 포함 파일

- `HubOnTrade_SNS_Full_Interactive_UI.html` — 단일 파일, 별도 설치 없는 UI
- `src/styles.css`, `src/app.js` — 수정 가능한 원본 분리 버전
- `DEVELOPMENT_HANDOFF.md` — 시스템 이관·백엔드·SaaS·API·검수 지시서
- `previews/` — PC·모바일 화면 이미지

실제 저장소·DB를 직접 열어 수정한 산출물은 아닙니다. 개발팀은 **보안 게이트(S1~S8)를 먼저 감사**한 뒤 기존 구현 기능을 옮겨야 합니다.
